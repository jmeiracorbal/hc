02

Cocos: language packs that aren't in the binary

Built-in today: Go, Python, JavaScript, TypeScript/TSX, Rust (in-process tree-sitter). Other languages ship as separate wasm cocos. Install on the machine, keep one hc binary. Official starters (hc/java, hc/php, hc/csharp) are regex-based reference packs, not full tree-sitter grammars.

⬡

Separate git repo

A coco is coco.toml plus a wasm32/wasi module released on GitHub. Pin with github.com/org/repo@vX.Y.Z.

↻

Install, then index

hc coco install … stores the pack under ~/.local/share/hc/ and registers it in hc.db. The next index/update/init loads it via wazero.

≡

Contract wasm/v1

Required exports: coco_abi_version, coco_alloc, coco_free, coco_parse. Host is Go + wazero.

⌖

Project pins

Optional hc.toml next to .hc can list coco ids and map extensions → packs so the team shares one set.

shell add a language pack 
hc coco install github.com/org/hc-java-coco@v0.1.0
hc coco list
hc coco uninstall hc/java

# while developing a coco checkout
hc coco install --local ../official-cocos/hc-java-coco --replace

03

It's a SQLite file on disk. That's the point.

Parsers fill ~/.local/share/hc/hc.db. Projects opt in with a .hc marker. You get CLI answers and an MCP server from the same index. Nothing remote to sync.

Updates stay cheap

hc update hashes files; only the dirty ones get reparsed. Deletes get pruned.

Graph before you edit

explore, impact, path: callers, callees, and a path between two symbols when you need it.

Search that isn't vibes

FTS5 over names, signatures, docstrings. If it isn't in the text, it won't hallucinate a hit.

04

Hooks that block the expensive Read

With a .hc marker, PreToolUse blocks full-file Read/Grep and returns symbols + range hints instead (ranged Read with offset+limit still passes). PostToolUse runs hc update after edits.

MCP tools

hc_search, hc_symbol, hc_file_context, hc_package, hc_explore, hc_impact, hc_path, hc_status. Require .hc in the project cwd.

Skills

hc setup installs hc-index, hc-navigate, hc-graph, and hc-doctor.

After upgrades

hc upgrade --install --yes re-execs the new binary with doctor --fix for pending schema migrations and safe repairs.

05

Install the binary. Index the project.

macOS and Linux, amd64/arm64. Checksummed from GitHub Releases.

install
curl -sSf https://raw.githubusercontent.com/jmeiracorbal/hc/main/install.sh | bash
hc init

install.sh runs hc setup (shared DB + hooks/skills). Then hc init in a project writes .hc, indexes, and registers MCP. Extra languages later: hc coco install ….
